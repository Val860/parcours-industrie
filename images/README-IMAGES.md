# Dossier images — organisation par rubrique

Les images du site sont rangées selon les catégories du menu. Cela permet de
remplacer une image sans chercher dans toutes les pages.

## Structure

| Dossier | Usage |
|---|---|
| `accueil/` | Page d'accueil : hero, bande photos, fond spécialisations |
| `vae/` | Pages VAE et diplômes |
| `bilan/` | Page bilan de compétences |
| `reconversion/` | Pages reconversion |
| `orientation/` | Pages orientation |
| `coaching/` | Pages coaching emploi |
| `entreprises/` | Pages entreprises |
| `ingenierie/` | Pages ingénierie de formation |
| `blog/` | Images des articles et de la page blog |
| `a-propos/` | Page à propos |
| `icons/` | Icônes des cartes de services de la page d'accueil |

## Comment remplacer une image

1. Ouvrir le dossier de la rubrique concernée.
2. Remplacer l'image en gardant exactement le même nom de fichier.
3. Garder le même format (`.jpg` pour les photos, `.png` pour les icônes).
4. Compresser l'image avant dépôt, idéalement sous 250 Ko pour les photos.

Aucune page HTML n'est à modifier si le nom du fichier reste identique.

## Recommandations

| Type | Format conseillé |
|---|---|
| Photos de section ou hero | `.jpg`, largeur 1400 à 1920 px |
| Background accueil | `.png` ou `.jpg`, idéalement 1920 × 1080 px |
| Icônes services | `.png`, fond transparent, 512 × 512 px |

## Notes

Certaines images existent dans plusieurs dossiers, car elles sont utilisées
dans plusieurs rubriques. C'est volontaire : chaque rubrique reste autonome et
plus facile à gérer pour un non-développeur.
